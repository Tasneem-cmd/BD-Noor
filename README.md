# Noor Malik's Birthday Surprise 🎂

A mobile-friendly, interactive birthday website made with plain HTML, CSS, and JavaScript.

## How it works
- Each scene is hidden until Noor taps the button to reveal it.
- The experience stays on one screen: no vertical or horizontal slide deck and no page scrolling.
- On the cake screen, she taps each candle to blow it out before continuing.
- The playful 19 October gift exchange appears as its own reveal, followed by a heartfelt birthday dua.
- No quiz, food instructions, Free Fire reference, or unrelated jokes.

## Publish on GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the repository root, replacing the old files. In Settings → Pages, select `main` and `/(root)`.
